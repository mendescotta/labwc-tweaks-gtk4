# Upstream review

Issue and PR title/body inventory retrieved from GitHub on 2026-11-09. This is a triage, not a complete review of every diff and discussion.

Implemented protections: invalid XML fails closed; edits preserve unrelated nodes and per-device settings; only changed values are written; Close never saves; empty XKB layout is rejected; cursor sizes are validated; system rc.xml is inherited when the user file is absent; LABWC_CONFIG_DIR is honored; reload uses labwc -r; application identifiers do not conflict.

Relevant references: Qt #11, #15, #75, #79, #89, #91, #124, #134, #210, #225, #270, #273; GTK #3, #8, #29, #37, #38, #39, #53. Custom acceleration configuration is preserved when untouched; edited and removed curves are supported.

Implemented since initial triage: all 53 scalar settings from the Qt pages, theme discovery across XDG locations, keyboard layout/variant selection, group-switch shortcuts, all three custom acceleration curves, touchscreen matrices, config-directory CLI option, build/session information, upstream label translations, numeric bounds and dependent-control sensitivity.

Settings parity baseline: labwc/labwc-tweaks commit 0cfcec57f464f7099a7bfadb9862c53697094e52.
GTK reference: 5cb8680865c72d1b9c9dfd5b41fb5f2bb58e22d9.

The subsequent gap review adds structured collection editing (including device profiles), environment.d precedence/editing and automatic XFCE config detection. GTK application-theme/GSettings synchronization remains outside the Qt settings baseline; arbitrary GTK_THEME assignments can be edited through Environment.
